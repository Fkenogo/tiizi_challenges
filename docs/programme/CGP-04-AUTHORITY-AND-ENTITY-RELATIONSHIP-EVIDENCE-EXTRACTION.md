### 7.2 Non-Interchangeability Rules (EOG-01 §6)

EOG-01 expressly declares 12 relationship pairs that are NOT interchangeable:

| Pair | Distinction |
|------|-------------|
| Authority ≠ Accountable Steward | Authority establishes truth; steward answerable for governance |
| Steward ≠ Custodian | Steward accountable for subject; Custodian preserves for purpose |
| Custodian ≠ Operator | Custody = preservation; Operation = continuity |
| Administrator ≠ Operator | Administration = consequential action; Operation = reliability |
| Contributor ≠ Authority | Contribution = input; Authority = establishes within scope |
| Participant ≠ Contributor | Participation = governed relationship; Contribution = attributable input |
| Participant ≠ Authority | Participation creates no general source Authority |
| Originator ≠ Authority | Origin = who expressed; Authority = authoritative status |
| Governed Subject ≠ Information Subject | Governed = what standards govern; Information = whom info concerns |
| Delegate ≠ Accountable Steward | Delegate = limited Authority; Steward = does not transfer |
| Presenter ≠ Authority to Establish Truth | Presenter communicates; does not create truth |
| Downstream User ≠ Custodian | Use = consumption; Custody = preservation responsibility |
