## 4. Batch Review Sequence

For each observation in the current batch:

1. confirm the Observation ID;
2. review the proposition IDs;
3. review the neutral summary;
4. review the supporting evidence;
5. select one disposition: Accept, Reject, Defer or Needs clarification;
6. record Founder rationale;
7. select Yes or No for amendment follow-up; and
8. leave the future amendment programme reference blank unless a separate programme reference already exists.

The session moves through Batches A through F in sequence. Batch order organizes review only and does not rank observations.

## 5. Disposition Boundary

An observation disposition records the Founder’s treatment of the observation. It does not itself:

- amend constitutional wording;
- merge, delete or rewrite propositions;
- establish an amendment programme;
- approve or adopt a constitutional instrument;
- create constitutional effect; or
- update programme or decision-register state.
