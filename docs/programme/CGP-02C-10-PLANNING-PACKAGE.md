## 4. Proposed Constitutional Scope

The future package would be bounded to the constitutional meaning, purpose and integrity requirements of Historical Preservation, including historically applicable governance, attributable decisions and historical status context.

It would distinguish preservation from:

- amendment traceability;
- supersession;
- retirement, withdrawal and rejection;
- storage;
- archival mechanisms;
- retention policy;
- repository implementation;
- Governance Index and Status Integrity; and
- Validation Rules.

This section identifies scope only. It defines no constitutional treatment.

## 5. Explicit Exclusions

Every exclusion in the [Proposed Work Package Definition](CGP-02C-10-PROPOSED-WORK-PACKAGE-DEFINITION.md#6-explicit-exclusions) binds any later authorization.

In particular, no planning or drafting under this proposed package may define storage, archival or retention mechanisms; repository implementation; Governance Index; Validation Rules; technical formats; a Platform Authority; accountability allocations; or an actual historical status determination.
