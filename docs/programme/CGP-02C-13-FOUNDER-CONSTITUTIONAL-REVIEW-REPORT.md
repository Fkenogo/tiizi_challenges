## 4. Founder Disposition Fields

Each observation provides these disposition choices:

- **Accept** — accept the observation as a relationship record;
- **Reject** — do not accept the observation as recorded;
- **Defer** — leave the observation for later attributable review; or
- **Needs clarification** — require further explanation before disposition.

Each entry also provides fields for:

- Founder rationale;
- amendment follow-up required, with Yes or No left unchecked; and
- a blank future amendment programme reference.

These fields do not predetermine the Founder’s decision. Accepting an observation does not itself amend, merge, delete or rewrite any proposition.

## 5. Review Instructions

For each observation:

1. review the proposition IDs, source documents, neutral summary and supporting evidence;
2. select one Founder disposition;
3. record Founder rationale;
4. select whether amendment follow-up is required; and
5. if applicable, record a future amendment programme reference only after one has been separately established.

No disposition should be inferred from an unchecked field, silence, document completion or passage of time.
