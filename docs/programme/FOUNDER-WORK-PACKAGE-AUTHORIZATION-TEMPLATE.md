# Founder Work Package Authorization Template

**Document type:** Reusable programme-governance record template

**Programme:** Tiizi Version 2

**Template status:** Founder-approved integrated programme-governance template; completing this template does not itself authorize work

## 1. Use Boundary

Use this template to prepare and record one attributable Founder decision for one bounded work package. Do not reuse one completed record for another package.

Delete instructional text in square brackets only when preparing a package-specific record. Do not delete applicable non-effects or exclusions.

## 9. Authorization Non-Effects

This decision:

- authorizes only the identified bounded work package;
- approves no future deliverable;
- creates no constitutional doctrine or meaning;
- creates no Platform Authority;
- allocates no accountability relationship, role or permission;
- completes no package, phase or stage;
- authorizes no successor package;
- resolves no deferred matter unless expressly stated in the decision;
- does not amend approved governance;
- does not update the Master Programme by itself; and
- permits no work before all entry gates and required programme synchronization pass.
