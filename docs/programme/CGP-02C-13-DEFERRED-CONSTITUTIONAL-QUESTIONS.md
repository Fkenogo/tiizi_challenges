## 1. Purpose

This register consolidates genuinely deferred constitutional questions that remain open across the authorized CGP-02C corpus. It presents only questions that the packages explicitly removed from current constitutional treatment and reserved for later attributable governance.

It does not reopen resolved decisions, manufacture entries, upgrade status, or create an amendment programme.

## 2. Classification Discipline

Each candidate item is classified before inclusion:

- A — genuine unresolved constitutional question (no disposition yet);
- B — intentionally deferred constitutional question (explicit deferral preserved);
- C — resolved Founder decision (EXCLUDED from D17);
- D — implementation/engineering matter (EXCLUDED);
- E — generic FEF/governance-admin matter (EXCLUDED);
- F — historical wording that no longer represents current state (EXCLUDED).

Only categories A and B are entered. All items below are category B — intentionally deferred via attributable Founder decisions or planning exclusions. Per governing records:

- CRA-001 through CRA-045 are resolved and MUST NOT be reopened;
- all 45 amendment-follow-up fields are No;
- absence of whole-instrument approval is a lifecycle state, not automatically a deferred constitutional question;
- future adoption is a lifecycle action, not automatically a deferred question;
- generic FEF evolution must remain outside the Tiizi constitutional instrument.
