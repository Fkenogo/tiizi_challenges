## 10. Planning Risks and Controls

| Risk | Planning control |
|---|---|
| Retirement is treated as supersession without replacement | Preserve C.8’s express distinction and keep each treatment independently attributable. |
| Withdrawal is inferred from non-use or repository removal | Preserve anti-inference and exclude implementation and repository activity. |
| Rejection is treated as approval, adoption or constitutional effect | Preserve C.3 and C.4 distinctions. |
| The three terms are collapsed into one status | Require separate treatment and mutual-boundary analysis within one subject. |
| Historical Preservation is defined prematurely | Limit the package to separation from deliverable 14. |
| A label, record or index creates status | Preserve the distinction between constitutional act and representation. |
| A recorder or repository administrator gains Authority | Preserve existing Governance Authority and exclude allocation. |
| Programme readiness is mistaken for authorization | Require attributable FWA-01 through FWA-05 decisions, validation and Master Programme synchronization. |

These controls define drafting boundaries only.
