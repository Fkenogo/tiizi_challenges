# 2. Family Definition

## Push

A Push exercise is any movement whose dominant action requires force to be generated by pushing an object or the body away from the centre of mass.

Primary movers commonly include:

- chest
- shoulders
- triceps

Secondary stabilisation frequently includes:

- core
- glutes
- scapular stabilisers

# 15. Governance Notes

The Push family deliberately separates:

- canonical movements,
- regressions,
- progressions,
- equipment variants,
- aliases.

This prevents the uncontrolled duplication observed in the audit, where spelling variants, template activities and test fixtures all appeared as separate identities.

Similarly, metric ownership remains with the exercise, while challenge policies determine how those metrics are used, preserving the ownership boundaries established in the earlier governance phases.
