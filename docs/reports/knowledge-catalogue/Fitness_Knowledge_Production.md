# Fitness_Knowledge_Production

## Objective

Transform every existing fitness exercise into a governed **Knowledge Item** that complies with all approved architecture documents.

Each exercise will be reviewed individually and assigned a definitive place within the Tiizi knowledge ecosystem.

---

# Production Workflow

Every exercise passes through the same pipeline.

## Stage 1 — Identity

Assign:

- Canonical Knowledge ID
- Canonical Name
- Short Name
- Synonyms
- Search keywords

---

## Stage 2 — Taxonomy

Assign:

- Domain
- Family
- Sub-family
- Exercise Type
- Movement Pattern
- Primary Goals
- Equipment
- Audience
- Safety Tier
- Difficulty Profile

---

## Stage 3 — Technical Contract

Define:

- Approved Metrics
- Approved Units
- Target Direction
- Tracking Methods
- Challenge Eligibility
- Verification Options

---

## Stage 4 — Behaviour Mapping

Link to:

- Progress Behaviour(s)
- Completion Behaviour(s)
- Ranking Behaviour(s)
- Aggregation Behaviour(s)
- Validation Behaviour(s)
- Finalization Behaviour(s)

No custom behaviour is permitted.

# Exercise Review Matrix

Every exercise receives one definitive decision.

| Decision | Meaning |
| --- | --- |
| Keep | Canonical exercise |
| Rename | Better canonical terminology |
| Merge | Combine duplicate concepts |
| Variant | Child of another exercise |
| Split | Separate two distinct concepts |
| Restrict | Additional governance required |
| Retire | Remove from future catalogue |

---

# Canonical Record Template

Every approved exercise should ultimately have a record similar to:

| Section | Contents |
| --- | --- |
| Identity | ID, names, synonyms |
| Taxonomy | Domain, family, movement pattern |
| Technical Contract | Metrics, units, tracking |
| Challenge Contract | Policies, eligibility |
| Behaviour Mapping | Behaviour Framework references |
| Relationships | Parent, variants, substitutions, workouts |
| Content | Instructions, benefits, safety |
| AI Metadata | Recommendation and search tags |
| Governance | Versions, reviews, publication |

---

# Quality Gates

An exercise cannot enter the production catalogue until it passes:

- Identity validation
- Taxonomy validation
- Relationship validation
- Metric validation
- Challenge compatibility validation
- Behaviour mapping validation
- Content review
- Safety review
- Translation review
- Governance review

---

# Deliverables

Phase 3A will produce:

1. **Tiizi Fitness Knowledge Catalogue v2** — the canonical library of approved exercises.
2. **Exercise Rationalisation Matrix** — every legacy exercise mapped to its canonical disposition.
3. **Exercise Relationship Graph** — parent/variant, progression/regression, substitution and workout relationships.
4. **Launch Exercise Pack** — the curated set of exercises approved for the initial release.
