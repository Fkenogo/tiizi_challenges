# We also introduce Evidence Levels

This is one refinement I'd add to the governance model.

Every field should declare its evidence source.

For example:

| Level | Meaning |
| --- | --- |
| E1 | Constitutional rule (platform governance) |
| E2 | Widely accepted exercise science and coaching consensus |
| E3 | Tiizi editorial guidance and best practice |
| E4 | Contextual or implementation-specific recommendation |

This makes it clear which parts of a record are immutable governance, which are grounded in established practice, and which are editorial choices that may evolve.
