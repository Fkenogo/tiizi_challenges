## Decision trace

| Decision | Information-governance effect |
|---|---|
| IDP-01 | Establishes visibility classes, minimum disclosure and deny-by-default access. |
| IDP-02 | Requires visibility controls to be enforceable and truthful. |
| ACT-01 | Establishes one canonical activity-event contract and permits governed domain extensions. |
| ACT-02 | Distinguishes participant submission intent from trusted acceptance and derived authority. |
| KNW-01 | Establishes one governed runtime catalogue authority and constrains local assets. |
| ADM-01 | Establishes least privilege, trusted high-impact authority and immutable sensitive-action accountability. |
| PLT-01 | Requires information governance to support the approved group-first platform identity. |
| PLT-02 | Requires personal information capabilities to support group participation without creating individual-challenge mode. |
| PLT-03 | Requires domain-neutral foundations with Fitness and Wellness as launch domains. |
| PLT-04 | Prevents information concepts from implying individual challenges in Version 2 launch. |

## Deferred areas confirmed

The standard explicitly defers the Entity Ownership Register, Security Standard, lifecycle standards, Database Model, API Model, Implementation Mapping, retention, correction, deletion, verification behavior, challenge types, ranking, streaks, rewards, social governance, notifications and operational lifecycles.
