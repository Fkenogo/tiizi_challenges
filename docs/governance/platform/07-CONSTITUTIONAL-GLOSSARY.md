# Constitutional Glossary

Each term has one canonical definition in this glossary. Detailed relationships and exclusions are governed by the Platform Domain and Terminology Standard.

| Term | Canonical definition |
|---|---|
| Accepted Activity Event | The authoritative accepted record, established by Acceptance Authority, that a measurable Activity occurred in a governed context. |
| Accountable steward | The declared party accountable for stewardship of a Governed subject within approved boundaries; stewardship does not itself confer Authority to establish truth. |
| Activity | A governed behavior or action that may be performed and measured. |
| Activity Event | The canonical platform concept governing the representation of a measurable Activity occurrence; only an Accepted Activity Event is authoritative Activity Information. |
| Administration | The governed exercise of platform authority for approved operational purposes. |
| Administrator | An actor explicitly assigned Administrative Authority for a declared purpose and scope. |
| Attributable originator | The identifiable source of an expression or submitted information; origin does not itself establish authoritative truth. |
| Authority | The approved right and responsibility to establish or change governed state. |
| Authority to establish truth | The approved right and responsibility to establish a particular authoritative fact, state, calculation, Knowledge item or decision for a declared purpose. |
| Capability | A stable business ability the platform governs. |
| Challenge | A governed shared undertaking through which participants pursue a defined goal using measurable activities. |
| Challenge Type | A governed classification of challenge behavior. |
| Completion | The authoritative determination that approved completion conditions have been met. |
| Consent Record | The attributable record of a person's acceptance of identified terms or privacy conditions and their version. |
| Custodian | A party entrusted to preserve or handle information within an approved purpose without acquiring authority over its meaning. |
| Derived Truth | An authoritative value calculated from accepted evidence under approved policy. |
| Domain | A governed area of knowledge or platform responsibility with a defined boundary. |
| Evidence Eligibility | The Policy-governed determination that an Accepted Activity Event may be used for a declared calculation. |
| Feature | A specific product expression of one or more capabilities. |
| Feed | An ordered presentation of governed group-relevant activity or communication. |
| Fitness | A Version 2 launch domain governing approved physical-activity knowledge and activities. |
| Goal | A stated outcome toward which participation is directed. |
| Governed subject | An entity, relationship or information object governed as a distinct subject under Tiizi standards. |
| Group | The primary social and accountability context for Version 2 challenges. |
| Group First | The principle that group challenges, group accountability and shared progress are the primary Version 2 product model. |
| Identity | The governed identity context through which a Person is recognized and attributable. |
| Individual Challenge | A possible future governed capability that is excluded from Version 2 launch and is not an active challenge type. |
| Information subject | The Person, entity or governed matter to which information relates. |
| Interest | A governed or personal expression of a subject relevant to the person. |
| Knowledge | Governed meaning used by Tiizi to define concepts, activities, relationships and constraints. |
| Knowledge Asset | A governed unit of Knowledge with distinct identity, canonical meaning, declared authority and defined relationships. |
| Leaderboard | An authoritative or clearly identified presentation of ranked participant results. |
| Least Privilege | The principle that an actor receives only the visibility and action authority required for an approved purpose. |
| Local Asset | A packaged item whose non-authoritative purpose is explicitly governed. |
| Member | A person with a governed relationship to a group. |
| Metric | The governed dimension by which an activity or goal is measured. |
| Motivation | The platform capability of supporting sustained, meaningful participation. |
| Notification | A governed communication about an event, state or required attention. |
| Operator | An actor explicitly assigned Operational Authority for a declared purpose and scope. |
| Participant | A person with a governed relationship to a challenge. |
| Person | The human subject who may hold governed identity and participation relationships. |
| Platform | The shared governed foundation through which Tiizi capabilities operate. |
| Platform Operation | A governed activity required to keep the platform reliable, controlled and reviewable. |
| Policy | A governed rule set that constrains allowed behavior and authoritative calculation. |
| Profile | The governed representation of Identity and participation-supporting information. |
| Progress | The authoritative derived account of advancement toward a goal. |
| Projection | A subordinate representation of authoritative information for access, communication or analysis. |
| Presenter | An actor or authority that communicates information without acquiring authority over the underlying truth. |
| Ranking | The governed ordering of eligible results according to an approved rule. |
| Recognition | A truthful acknowledgement of governed participation or outcome. |
| Reward | A governed benefit or value granted under an explicitly approved reward policy. |
| Runtime Catalogue | The single governed authority that makes approved knowledge available for runtime use. |
| Runtime Projection | A governed, purpose-specific representation of a Knowledge Asset that remains subordinate to the Knowledge Asset and Runtime Catalogue authority. |
| Shared Progress | A common authoritative account of advancement toward a group challenge goal. |
| Streak | A governed pattern of qualifying participation across defined time periods. |
| Submission Intent | A Participant's attributable expression that an Activity occurred in a governed context, before trusted acceptance. |
| Downstream user | An approved consumer of information whose use does not alter the source's authority, meaning or stewardship. |
| Trusted Backend | The governed authority responsible for accepted events and authoritative derived platform truth. |
| Unit | The governed expression used to quantify a metric. |
| Verification | A governed determination about the evidential status of a submitted or accepted activity. |
| Visibility Class | An approved category controlling who may discover or access information. |
| Wellness | A Version 2 launch domain governing approved wellbeing knowledge and activities. |
