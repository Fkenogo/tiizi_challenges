# Document 00 — Cross-Reference Recommendations

## 1. Purpose

This document recommends how the existing Tiizi governance corpus could later reference [Document 00 — Tiizi Constitutional Ontology and Foundational Product Concepts](00-TIIZI-CONSTITUTIONAL-ONTOLOGY-AND-FOUNDATIONAL-PRODUCT-CONCEPTS.md).

These are recommendations only. No existing governance document is amended by this sprint.

## 2. Cross-Reference Rule

Future references should use Document 00 for conceptual purpose and foundational relationships. They should continue to use the Platform Constitution and approved standards for normative rules, Authority, information categories, ownership, lifecycle, permissions, privacy, security and implementation boundaries.

A reference to Document 00 must not:

- promote an ontological layer into a new entity automatically;
- create a Platform Authority;
- resolve stewardship or custody;
- turn conceptual dependence into a workflow;
- treat Persistence as a lifecycle state;
- treat time-boundedness as a completed lifecycle specification;
- treat Commitment as Evidence;
- collapse accepted facts, Evidence Eligibility and Derived Truth;
- represent a future domain as active.

## 5. Recommended Cross-Reference Language

Later amendments may use language such as:

> This standard is interpreted within the conceptual world defined by Document 00 — Tiizi Constitutional Ontology and Foundational Product Concepts. Document 00 supplies conceptual meaning; this standard supplies the approved governance rules within its declared scope.

Where Evidence is discussed, add:

> The ontology's statement that Commitment generates Evidence is conceptual shorthand. Submission Intent, Acceptance Decision, Accepted Activity Event, Evidence Eligibility and Derived Truth remain distinct under the Platform Authority Model.

Where Community is discussed, add:

> Community is the ontological layer expressed by the Tiizi Group. It does not create a separate entity, role, permission or public audience.

Where Undertaking is discussed, add:

> Undertaking is the ontological layer expressed by the Tiizi Challenge. It does not establish lifecycle states, calculations or Authority.
