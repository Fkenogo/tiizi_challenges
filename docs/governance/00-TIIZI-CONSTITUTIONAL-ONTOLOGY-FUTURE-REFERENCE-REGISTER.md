# Document 00 — Future Governance Reference Register

## 1. Purpose

This register identifies future Tiizi governance documents that should eventually reference [Document 00 — Tiizi Constitutional Ontology and Foundational Product Concepts](00-TIIZI-CONSTITUTIONAL-ONTOLOGY-AND-FOUNDATIONAL-PRODUCT-CONCEPTS.md).

It does not authorize the documents, determine their content or resolve their pending decisions.

## 2. Reference Principle

A future governance document should reference Document 00 when it defines or constrains:

- the purpose of a Community or collective context;
- the nature of an Undertaking;
- voluntary Commitment or Participation;
- Evidence or Truth;
- Motivation, Recognition or Reward;
- Growth;
- a future governed domain.

The reference should explain conceptual purpose only. The future document remains responsible for its own normative scope.

## 4. Required Reference Questions

Every future document that cites Document 00 should answer:

1. Which ontological concept does this document govern or support?
2. Does it refine a product expression without redefining the concept?
3. Does it preserve Community before competition?
4. Does it preserve Commitment as voluntary and distinct from Evidence?
5. Does it preserve Evidence as distinct from Truth and presentation?
6. Does it keep Recognition and Reward subordinate to truthful participation?
7. Does it describe Growth without guaranteeing or inventing it?
8. Does it keep future possibilities outside active scope until approved?

## 5. Non-Reference Cases

A document need not cite Document 00 merely because it concerns Tiizi. A reference is unnecessary where the document is narrowly evidential, temporary or administrative and does not interpret a foundational concept.

References should not become ceremonial. Each reference should explain a real conceptual dependency.

## 6. Status

**Status:** Prospective reference register. It creates no future document, approval, scope or implementation obligation.
