# Recommended Next Work Package — GRP Foundation Closure

**Status:** Recommendation pending Governance Authority approval

**Date:** 2026-07-21

## 1. Recommendation

The next constitutional work package should be:

**GRP Foundation Closure — Group Creation, Stewardship Continuity, Charter and Stewardship Council Readiness.**

This should be a decision-preparation and readiness package. It should not itself approve an outcome.

## 2. Rationale

Group is Tiizi's persistent governed Community and the mandatory context for Version 2 Challenges. The following remain unresolved despite the approved EOG-02 boundaries:

- which existing Platform Authority authenticates Group creation;
- how the singular Accountable Steward relationship continues after reassignment, relinquishment or creator departure;
- how Charter truth remains distinct from Group identity and Administration;
- how a Stewardship Council supports but never replaces Accountable Stewardship; and
- whether C-GRP-08 receives permanent inventory treatment under CG-08.

These questions precede CHL-01. Beginning with Challenge governance would otherwise risk relying on an incomplete Group continuity model.

## 3. Authorized Scope Recommendation

The work package should prepare, but not decide:

1. Group creation-authentication options using only the eleven approved Platform Authorities;
2. GRP-02 stewardship continuity options consistent with exactly one Accountable Steward relationship;
3. Charter Authority, stewardship, custody and historical-boundary questions without allocating holders;
4. Stewardship Council constitutional-scope and CG-08 classification options;
5. consequences for later GRP-01, GRP-03 and GRP-04 work; and
6. affected EOG-05 rows and later allocation dependencies.

## 4. Excluded Scope

The package should not:

- define membership lifecycle;
- resolve GRP-01, GRP-03 or GRP-04;
- define roles or permissions;
- allocate administrators, custodians or operators;
- define moderation workflow;
- amend EOG-02 or EOG-05;
- resolve CHL, ACT, KNW, MOT or RSK decisions; or
- introduce implementation.

## 5. Recommended Deliverables

1. GRP Foundation Closure Readiness Review.
2. Founder Decision Agenda.
3. Constitutional Options and Trade-off Paper.
4. EOG-02 and EOG-05 Impact Map.
5. Founder Decision Sequence.
6. Validation Report.

Every recommendation should be labelled **Recommended — pending founder approval**.

## 6. Entry and Exit Gates

**Entry gate:** EOG-01, EOG-02 and EOG-05 remain authoritative and unchanged.

**Exit gate:** the package is complete when the founder can decide Group creation authentication, stewardship continuity, Charter foundations and Stewardship Council classification without additional constitutional analysis.

Approval of those decisions would occur in a separate founder approval task.

## 7. Downstream Effect

If later approved, the resulting decisions would:

- remove the first Group allocation blockers;
- supply the prerequisite for CG-08 closure;
- make GRP-01, GRP-03 and GRP-04 analysis more precise;
- stabilize the Group context required by CHL-01; and
- advance the programme toward the Classification Closure and Core Allocation Authority Milestone.

## 8. Recommendation Result

Proceed next with the GRP Foundation Closure decision-preparation package. Do not begin CHL-01 constitutional drafting or the Entity Relationship Allocation Register until this Group foundation has been reviewed through the normal founder-governance process.
